# PDF Nexus

A premium, client-side PDF manipulation tool suite.

## Features
- **PNG to PDF**: Convert images to PDF.
- **PDF Merge**: Combine multiple PDFs.
- **PDF Compress**: Basic optimization.
- **PDF to PNG**: Extract pages as images.

## How to Run

### Option 1: VS Code Live Server (Recommended)
1. Open this folder in VS Code.
2. Install the "Live Server" extension.
3. Right-click `index.html` and choose "Open with Live Server".

### Option 2: Python Simple Server
If you have Python installed, run this command in the terminal:
```bash
python -m http.server
```
Then open `http://localhost:8000` in your browser.

### Option 3: Direct Open
You can try opening `index.html` directly in your browser, but some features (like PDF to PNG) might not work due to browser security restrictions on local files.
